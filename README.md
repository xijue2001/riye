## Windows 开始使用

1. 下载 Windows x64 压缩包，完整解压到一个固定位置。
2. 打开解压后的文件夹，双击 **Riye.exe**。无需安装 Node.js、Python 或 Docker。
3. 在“今天”直接输入文字。点击“勾选项”插入可选的复选框；图片可通过按钮选择、拖入或粘贴截图。
4. 查看右侧“参考前几天”，选中要延续的文字，再点击“带入选中文字”。原日期记录保留。
5. 在“我的计划”创建指定日期、每周重复或课程/阶段安排。

本版面向 Windows 10/11 的 x64 电脑。如果电脑是 ARM 或 32 位，请先告知。

## 日常操作

- 点击页面日期打开记录月历：绿色点表示写过打算，紫色点表示写过日记，空心点表示未写。只保存空白文字不计入已写；仅有图片的日记计入。
- 没有固定安排时只显示“当天计划：无”和“＋ 添加计划”。
- “过往记录”可删除某一天的打算和日记。固定计划不受影响；删除会同步，原图和历史版本仍保留。勾选“显示已删除及空白记录”可进入历史版本恢复。正常删除仍会同步。如果删除与另一台设备尚未同步的非空修改并发，按新规则自动保留有内容的修改；删除版本仍留在历史中。
- 在“同步与备份 → 本机设备名”分别填写“手机”“公司电脑”“家里电脑”。最近编辑、历史版本和冲突比较会显示来源。旧记录可沿用同一设备ID补上名称；未升级或未同步名称的设备暂显示短编号。
- 日记显示首次记录时间，精确到秒；继续编辑不改变该时间。新版从第一次非空编辑记录，旧日记从最早的非空历史版本恢复，无法补出早于历史记录的真实时间。
- 同步会在上传后重新检查其他设备的内容；同步中新增的文字与图片一起排队。仍有待处理内容时不会显示全部完成。

建议三端升级到0.1.5。更新前可先导出一次完整备份；Windows用新版解压目录运行，Android用原签名新版APK覆盖安装，均继续使用原本地数据与NAS目录。

## 计划怎样显示

- 指定日期：适合演唱会、聚会、办事，可填写时间和具体内容。
- 每周重复：选择多个星期，为每个星期分别填写内容；需要相同内容时分别粘贴即可。
- 课程/阶段：每节课填写名称、日期、时间和具体内容。第2课没学完，第3课仍按原定日期出现。
- 当天安排点开可看全文。“追加到另一天”会另加一次安排，保留原来的日期；也可在计划编辑里直接调整课程日期。

## 设置现有 WebDAV

打开“同步与备份”：

1. **常用地址**填写现有服务地址，带上协议和端口；如果现有服务有 `/dav` 等路径，也要保留。示例：`http://100.x.x.x:6086`。
2. **备用地址**可填家里的内网入口。两个入口必须访问同一服务、同一目录。
3. **专用目录**可使用 `/sata2-2/riye`，需要按现有服务的实际目录填写。不要使用 Cherry Studio 的现有备份目录。
4. 填写 WebDAV 的账号与密码。账号、连接设置和密码不进入同步或备份；Windows 使用系统保护保存密码。
5. 点击“测试读写”。它会在专用目录内创建并删除一个临时测试文件。
6. 保存设置，然后点击“手动同步”。两台电脑填写同一服务和目录，各自保存自己的连接设置。

开启自动同步后，按所选间隔定期同步；启动软件或保存连接设置后重新计时。编辑会立即保存到本机，等待下一次定时同步。修改间隔会取消原计时；关闭自动同步后只在手动点击时同步。手动同步不受间隔限制，手机继续前台手动同步。NAS 不可达时继续本地保存，侧边栏会显示同步未完成。仅“已保存在本机”不表示已经同步到另一台设备。

同一段内容被两台设备分别修改时，空白与相同版本自动归并；只有两方都有内容且不同时才需要手动选择。点击侧边栏的“需要比较”选择当前版本；日记和打算可点击“合并以上正文”保留全部不同的内容。其他版本仍能在“历史版本”里查看。

## 备份和更新

- 本地数据默认位于 `%APPDATA%\日页\data-v1`，与软件解压目录分开。
- 软件保留最近7份每日自动备份；某一天已有记录时，在首次后续编辑前保存当时的数据。
- “导出完整备份”生成 ZIP，包含文字、勾选状态、编辑历史和原图。如有图片尚未下载，会提示先同步。
- “恢复”先另存当前数据，再恢复备份中包含的记录；备份没有的记录继续保留。恢复结果也会作为新版本同步。
- 可把导出的备份放到另一台电脑、移动硬盘或其他自行选择的位置。
- 更新软件时，使用新版解压目录运行即可继续读取同一份本地数据。

## 源码与开发

界面代码与平台无关的数据结构保存在 `renderer/` 和 `core/`；Windows系统交互在 `desktop/`。安卓平台接口位于 `android/` 与 `mobile/`，提供私有文件存储、系统图片与备份选择器、KeyStore 密码保护和原生 WebDAV 传输；沿用相同版本记录格式。

`npm test` 运行核心测试，不需要安装第三方运行依赖。

`python3 scripts/get-runtime.py .runtime win32` 下载并校验官方运行时；`python3 scripts/package.py` 创建 Windows 可运行包和源码包。

桌面UI测试需要 Playwright 与 Linux Electron，可运行 `PLAYWRIGHT_MODULE=<playwright包路径> node tests/ui.cjs`。
