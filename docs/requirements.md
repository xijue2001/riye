# 日程管理应用：需求说明

更新日期：2026-10-14（北京时间）
状态：Windows 第一版已通过用户初步试用；Android 第一版安装包已生成，等待Redmi实机试用。
开发顺序：Windows 电脑端先完成，Android 端沿用相同数据与同步规则。

## 1. 产品目标

把每天的打算、日记、长期计划和指定日期安排放在一起。以“一天一页”为主要入口，打开就能看到当天安排，能自由写文字、加入照片，能参考过去的打算继续安排今天。

## 2. 已确认的使用环境与约束

- 家里一台 Windows 电脑，公司一台 Windows 电脑，两台都可以正常安装软件；一台 Windows 10，一台 Windows 11；均可正常安装软件。
- 一台安卓手机：红米 K70 Pro，澎湃 3.0，安卓 16。
- 家里一台 iStoreOS NAS，稳定性一般；尽量不新增 NAS 服务、不自行配置 Docker。
- 现有 WebDAV 曾在 Cherry Studio 中成功备份；用户已提供现有 NAS WebDAV 读写成功截图；两台电脑互传结果未单独记录。
- 家里可以走内网；远程设备使用 Tailscale 或既有远程连接方式。
- 手机接受按需断开 v2rayNG、连接 Tailscale完成同步，然后切回代理。
- 暂时不使用 Google Drive；第一版不依赖云盘订阅。

## 3. 已确认的核心功能

| 模块 | 要求 |
|---|---|
| 每日打算 | 自由写整段文字，允许在正文插入可手动勾选的事项 |
| 参考过去 | 写今天时查看前几天的打算，切换参考日期，选中文字带入今天 |
| 内容延续 | 追加到今天，保留原日期原文；不默认自动迁移全部未完成事项 |
| 日记 | 按日期编辑；照片和截图穿插在文字中 |
| 固定计划 | 同一份内容按星期重复出现 |
| 星期计划 | 同一计划可在不同星期显示不同内容 |
| 阶段与课程 | 支持不同课程与训练阶段，按各自原定日期显示；漏学的课程由用户另行安排 |
| 日期安排 | 支持某一天的演唱会、聚会、办事等，允许时间和备注 |
| 提醒 | 打开时清楚展示当天与即将到来的安排；定时通知优先级低 |
| 完成操作 | 勾选可选，不要求每天逐项打卡 |

## 4. 已确认的数据保存与同步方向

- 客户端先保存本地数据；NAS 不可用时仍能编辑、保存、查看已有内容。
- 三台客户端通过现有 WebDAV 交换记录和照片，NAS提供文件存储。
- Windows 软件打开期间，在连接可用时自动同步；始终提供手动同步按钮。
- 安卓端提供前台手动同步，方便按需切换 VPN。
- 应用使用独立同步目录，接入时在客户端配置地址、账号和目录。
- 不把完整备份包直接覆盖当作多设备同步。
- Google Drive 不纳入当前方案。

## 5. 建议采用的默认规则（尚非逐项用户确认）

- 每日打算、日记、计划分别保存与同步，减少互相干扰。
- 同一段内容两端分别修改时保留冲突版本，供用户比较和处理；不按时间直接覆盖。
- 连接失败时保留待上传内容，恢复连接后继续；文字与图片分别显示同步状态。
- 同步成功须确认相关图片也已完成，不能仅凭文字上传完成就显示全部成功。
- 历史备份与同步分开，电脑保留可恢复的历史版本。
- 支持导出、恢复包含文字和照片的完整备份包；导出时明确显示是否有照片尚未下载。
- 图片支持选择文件、拖入、粘贴截图。
- 修改长期计划时保留过去日期当时的内容；以后日期使用新规则。
- 删除内容先保留可恢复记录，恢复备份前另存当前数据。
- 电脑端优先完整保存文字和照片；手机照片缓存范围后续确认。

## 6. 拟定页面

1. 今天：当天安排、每日打算、日记、前几天参考区、保存与同步状态。
2. 计划：具体课次与训练内容、重复星期安排、课程顺序、指定日期安排。
3. 历史：按日期翻阅过去内容；搜索能力拟纳入第一版。
4. 设置：WebDAV连接、同步状态、冲突处理、备份导出与恢复。

页面名称和视觉细节允许在试用时调整。

## 7. 制作前尚需明确

1. 已确认：课程按原定日期显示，不因漏学自动顺延；用户另行安排漏学课程。
2. 已确认：只保存每节课或每次训练的具体内容；不单设完整计划原文。
3. 已确认：一台 Windows 10、一台 Windows 11；默认制作 x64 版本。
4. 现有 WebDAV 的连接、独立目录读写与图片传输能力：接入阶段实测，账号密码在客户端填写。
5. Windows可运行包的实际构建条件：选型与开发环境检查时验证。

## 8. 第一版验收场景

- 断开 NAS 后写打算、写日记、插入勾选项与图片；重启软件内容仍在。
- 从昨天选取两项带入今天，昨天原文不变，今天现有内容保留。
- 同一计划周一与周三显示不同内容；指定日期安排在对应日期出现。
- 课程显示遵循最终确认的推进规则。
- 两台电脑分别修改不同记录，恢复连接后两边都取得这些修改。
- 两台电脑分别修改同一段内容，能够看到并处理两份内容。
- 图片上传中断后能重试，不丢本地原图，不误报全部同步成功。
- 导出的备份能够恢复到另一个本地数据目录，文字、勾选状态和图片保持对应。
- 恢复或误删处理不会立即被另一台设备的旧状态覆盖。

## 9. 开始制作的判断

“约80%把握”不作为精确分数：主流程、书写方式、计划推进、同步规则、安装目标与恢复方式足够明确时开始制作。可在首次试用中调整的视觉细节，不阻碍开发。
