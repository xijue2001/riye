# 日页 0.1.2：精简界面与自动同步间隔

Windows 与 Android 更新为 0.1.2，Android versionCode 3。继续使用原本地数据与 NAS 同步目录。

- 删除月历底部重复的“跳转日期”输入框，保留日期点选、月份切换与“今天”。
- 清理截图中的编辑区、参考区说明，以及全应用类似的装饰性标语、英文标题和重复提示。
- Windows 在“同步与备份 → WebDAV 连接”新增“自动同步间隔”下拉框：5、10、15、30 分钟，1、2、4、6、8、12、24 小时，默认 5 分钟。
- 间隔在本机保存，重启后恢复。启动软件或保存连接设置后开始计时；修改间隔取消旧计时，关闭自动同步或退出后停止。编辑自动保存本机，等待下一次定时同步；手动同步随时可用。
- 手机继续沿用前台手动同步，界面清理同步更新。
