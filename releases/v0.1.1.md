# 日页 0.1.1：日期状态、设备来源与同步修复

Windows 与 Android 统一为 0.1.1，Android versionCode 2。安装包继续使用原本地数据与 NAS 同步目录。

- 日期选择改为记录月历：绿色表示已写打算，紫色表示已写日记，空心表示未写；空白草稿不计入，照片日记计入。
- 没有固定安排时仅显示“当天计划：无”和“＋ 添加计划”。
- “过往记录”可删除某一天的打算和日记。固定计划不受影响；删除会同步，历史版本与原图可恢复。另一台设备未同步的新修改保留为冲突。
- “同步与备份 → 本机设备名”可设置手机、公司电脑、家里电脑等，最近编辑、历史版本与冲突比较显示来源。旧设备升级并同步名称后也能识别历史记录来源。
- 日记首次非空编辑时间显示到秒，后续修改不改变。旧日记从最早非空版本恢复时间，不能补出早于历史记录的真实编辑时间。
- 修复同时同步时漏下载对方新版本、重启后子版本可能先于父版本上传，以及同步中新图片可能落后于正文上传。上传后重新检查，仍有内容等待时明确显示；历史列表接收同步后保留搜索条件并刷新。

## 更新

先在旧版导出完整备份。两台 Windows 电脑都下载 Windows ZIP，完整解压后运行新目录中的 Riye.exe；手机下载 APK，直接覆盖安装。APK沿用旧版签名，不需要卸载。建议三端都升级，然后分别设置设备名，再同步一次。

## 验证

26项核心测试、真实Electron桌面操作、移动窄屏操作、与原Windows 0.1.0的数据互通、Java私有文件与ZIP备份测试通过。Windows运行时逐文件复核，APK签名与资源完整性核对通过，原更新签名保持一致。附SHA256SUMS.txt。

本版尚待Windows 10/11、Redmi与真实NAS组合试用；当前环境未运行Android系统内安装测试，因此本Release标为Pre-release。此前Windows 0.1.0的用户试用反馈不当作新版实机验证。源码、历史标签和旧包保留，个人密码与签名私钥未上传。
