## 下载与更新

- Windows 10/11 x64：下载 `Riye-Windows-x64-v0.1.5.zip`，完整解压后运行 `Riye.exe`，关闭旧版再运行新版即可沿用原本地数据。
- Android 8.0 及以上：下载 `Riye-Android-v0.1.5.apk`，直接覆盖安装，保留日记与同步设置。
- `Riye-Source-v0.1.5.zip` 为源码，两个 Guide 为使用说明，`SHA256SUMS.txt` 可核对下载文件。

GitHub 继续标记为预发布，表示真实 Android 设备安装运行尚待验证；功能无试用期限或付费限制。建议电脑与手机同时更新到 0.1.5。
