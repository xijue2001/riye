# 日页 0.1.3：自动处理空白与相同版本冲突

Windows 与 Android 统一更新为 0.1.3，Android versionCode 4。原本地数据、NAS 目录与安卓更新签名沿用。

- 冲突版本全部为空：自动归并，不显示比较入口。
- 只有一方有内容：自动保留有内容的一方。
- 内容相同：忽略自动生成的块编号及空白占位，自动归并。
- 只有不同且非空的版本才要求选择。比较列表及“合并以上正文”跳过空白与重复版本；多台设备也遵循同样规则。
- 文字、照片、勾选状态与图片说明都计入内容，只有照片的日记不会误判为空；计划名称、日期、课次及生效日期继续保留。
- 启动时自动整理已有空白或相同内容的冲突，同步时处理新收到的冲突；原始历史与原图保留，首次日记时间与设备来源保留。

正常删除按版本关系生效；如果删除与另一台设备的非空修改并发，按“有内容优先”自动保留修改，删除版本仍在历史中。双方均删除时自动归并。

## 更新与验证

建议两台电脑和手机都更新。Windows 完整解压后运行新目录中的 Riye.exe；Android 直接覆盖安装，无需卸载。连接设置及数据目录保持原样。更新前可先导出完整备份。

39 项核心与计时测试、Electron 桌面及手机窄屏操作、原 Windows 0.1.0 互通、Java 文件与备份检查通过。已验证空白/重复过滤、人工选择、合并去重、多设备同时归并后收敛、不重复产生相同归并、保留首次时间与计划日期。Windows 官方运行时、APK 原签名和资源、源码包与发布附件校验值均已核对。
